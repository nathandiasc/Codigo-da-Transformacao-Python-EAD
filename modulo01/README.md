# 💈 Sistema de Vendas - Barbearia

## Funcionalidades Principais

O sistema foi desenvolvido para auxiliar no gerenciamento de produtos de uma barbearia por meio de uma interface gráfica simples e intuitiva.

### Funcionalidades disponíveis:
- Cadastro de novos produtos.
- Exibição em tempo real dos produtos cadastrados.
- Realização de vendas com atualização automática do estoque.
- Remoção de produtos do sistema.
- Atualização de preços.
- Reposição de estoque.
- Consulta do faturamento total obtido nas vendas.
- Busca de produtos pelo nome.
- Aplicação de descontos em produtos.
- Interface gráfica com mensagens de confirmação, alerta e erro.

---

## Tecnologias e Estruturas Utilizadas

### Linguagem
- Python 3

### Biblioteca
- Tkinter (Interface Gráfica)

### Componentes utilizados
- `Tk()` para criação da janela principal.
- `Label`, `Entry`, `Button`, `Frame` e `LabelFrame` para construção da interface.
- `Text` para exibição da lista de produtos.
- `messagebox` para mensagens de aviso, erro e confirmação.
- `ttk.Style` para personalização visual.

### Estruturas de programação
- Variáveis globais para armazenamento dos produtos.
- Funções para organização das operações do sistema.
- Estruturas condicionais (`if`, `elif`, `else`).
- Tratamento de exceções (`try` e `except`).
- Manipulação de interface gráfica baseada em eventos.

## Panorama Geral: O Sistema de Pedidos

O Sistema de Vendas da Barbearia foi desenvolvido para facilitar o gerenciamento de produtos comercializados em uma barbearia. A aplicação permite cadastrar produtos, controlar o estoque, registrar vendas, atualizar preços, aplicar descontos e acompanhar o faturamento obtido.

O sistema possui uma interface gráfica desenvolvida em Python utilizando a biblioteca Tkinter, tornando sua utilização simples e intuitiva. Todas as operações são realizadas por meio de botões e campos de entrada, permitindo que o usuário execute as ações sem necessidade de utilizar o terminal.

Além disso, o sistema realiza validações de dados, informa erros de preenchimento, controla automaticamente o estoque disponível e atualiza as informações exibidas em tempo real, proporcionando maior organização e praticidade na administração dos produtos da barbearia.
